Factory Inventory Management System

Architecture overview. Vue 3 single-page client, FastAPI server, in-memory mock data loaded from JSON files. There is no database.

System architecture

Tech stack

Frontend

  • Vue 3 (Composition API)
  • Vite dev server, port 3000
  • vue-router 4
  • axios
  • Custom SVG charts, CSS Grid

Backend

  • Python, FastAPI
  • uvicorn, port 8001
  • Pydantic models
  • uv for running (uv run python main.py)

Data

  • JSON files in server/data/
  • Loaded by mock_data.py
  • No database, no persistence

Tests and tooling

  • pytest + FastAPI TestClient (tests/backend)
  • Claude Code: 3 agents, 6 commands, 1 skill, 1 hook
  • MCP: playwright, github (.mcp.json)

API endpoints

All implemented in server/main.py. Every endpoint is GET.

EndpointFilters / paramsResponse
GET /noneWelcome message and version
GET /api/inventorywarehouse, categoryList of InventoryItem
GET /api/inventory/{item_id}path id; 404 if unknownInventoryItem
GET /api/orderswarehouse, category, status, monthList of Order
GET /api/orders/{order_id}path id; 404 if unknownOrder
GET /api/demandnoneList of DemandForecast
GET /api/backlognoneList of BacklogItem, with has_purchase_order flag derived from purchase orders
GET /api/dashboard/summarywarehouse, category, status, monthInventory value, low-stock count, pending orders, backlog count, orders value
GET /api/spending/summarynoneSpending summary
GET /api/spending/monthlynoneMonthly spending
GET /api/spending/categoriesnoneSpending by category
GET /api/spending/transactionsnoneRecent transactions
GET /api/reports/quarterlynoneQuarterly statistics computed from orders
GET /api/reports/monthly-trendsnoneMonthly trends

Gap in the code: client/src/api.js also calls /tasks (GET, POST, plus delete and toggle helpers) and /purchase-orders (POST, GET by backlog item id). No matching routes exist in server/main.py, although the PurchaseOrder and CreatePurchaseOrderRequest models are defined there.
